# ClimateVision

Система машинного обучения для классификации сезонов и месяцев по фотографиям. Проект использует мультимодальный ансамблевый подход, объединяя визуальные признаки изображения с географическими и климатическими метаданными (координаты, температура).

Интерфейс взаимодействия реализован в виде Telegram-бота. Оркестрация пайплайна построена на базе графовой архитектуры LangGraph.

Проект настроен для развертывания на облачных платформах (например, Render) в режиме Web Service. Бот использует метод Long Polling. Для предотвращения остановки контейнера на бесплатных тарифах предусмотрен эндпоинт /health, который можно пинговать внешними сервисами (UptimeRobot).

## Технический стек
Оркестрация: LangGraph, LangChain

Машинное обучение: PyTorch, Transformers (HuggingFace)

Модели: google/siglip-base-patch16-224 (Fine-tuned), meta-llama/llama-4-scout-17b-16e-instruct, llama-3.3-70b-versatile

Бэкенд: Python-Telegram-Bot, Flask, Render

Внешние API: Open-Meteo

## Особенности архитектуры

 **Многоуровневая классификация:** Определение макро-сезона (4 класса) и конкретного месяца съёмки (12 классов).
 **Адаптивность к входным данным:** Система способна работать с минимальным набором данных (только фото) и с максимальным (фото + точные координаты + текущая температура + любая уточняющая информация).
 **Ансамбль моделей:** 
    SigLIP (70% веса): Локальная модель (дообученная на 68 044 изображениях). Обрабатывает климатические признаки и выдает базовое математическое предсказание (Accuracy 86.43%).
    Vision LLM (30% веса): Облачная мультимодальная модель (Groq / Llama). Анализирует мелкие визуальные детали (листва, снег) и формирует итоговый вывод, решая спорные случаи.
 **Графовый пайплайн (LangGraph):** Процесс разделен на независимые узлы (маршрутизация, парсинг, анализ, синтез, форматирование).
 **Локальный RAG:** Использование легковесного JSON-справочника климатических норм для валидации температурных показателей без развертывания векторных баз данных.
 **Оптимизация API:** Встроенное хэш-кэширование запросов и Rate Limiter.

## Структура репозитория

 
ClimateVision/
├── app.py                 # Точка входа, инициализация Telegram-бота и Flask health-check
├── config/                # Конфигурационные файлы (Hydra)
├── core/
│   ├── analyzer.py        # Узел визуального анализа (Vision LLM API)
│   └── siglip.py          # Инициализация и инференс локальной модели SigLIP
├── graph/
│   ├── builder.py         # Сборка графа LangGraph
│   ├── nodes.py           # Логика узлов (router, analysis, synthesis, formatter)
│   └── state.py           # Структура состояния (AgentState)
├── rag/
│   └── retriever.py       # Извлечение климатического контекста (справочник норм)
├── cache/                 # Логика кэширования ответов
├── middleware/            # Rate limiter и защита от спама
├── utils/                 # Валидаторы, парсеры данных, логгер, сбор метрик
└── models/                # Директория для весов SigLIP (best_model.pth)

#Требования и установка


1. Клонируйте репозиторий:


git clone [https://github.com/your-username/ClimateVision.git](https://github.com/your-username/ClimateVision.git)
cd ClimateVision

2. Установите зависимости:


pip install -r requirements.txt

3. Скачайте веса дообученной модели SigLIP и поместите файл best_model.pth в директорию models/siglip-season-model/.

4. Создайте файл .env в корневой директории и добавьте необходимые API-ключи:

BOT_TOKEN=ваш_токен_telegram_бота
GLM_API_KEY=ваш_ключ_zhipu_glm
GROQ_API_KEY=ваш_ключ_groq

5. Для локального запуска выполните:


python app.py
